Initial scaffold release of the **application-security-engineer** role.

- Advisory AppSec agent that secures the SDLC; read-only by default, never blocks
  merges, no exploitation beyond authorized DAST against an owned app.
- Seven bundled skills: `secure-code-review`, `sast-orchestration`,
  `dast-orchestration`, `dependency-and-sca-scanning`, `supply-chain-review`,
  `threat-modeling`, `appsec-reporting`.
- Standards: OWASP ASVS & Top 10, CWE, OWASP SAMM, STRIDE.
- APT tool layer (`nikto`, `jq`, `ripgrep`); non-apt scanners (semgrep, bandit,
  trivy, grype, syft, osv-scanner, OWASP ZAP) documented in `tools/README.md`.
- Optional, all-read-only env vars: `SEMGREP_APP_TOKEN`, `SNYK_TOKEN`,
  read-only `GITHUB_TOKEN`, `NVD_API_KEY`.
- Offline pytest scaffold smoke test over the manifest and every `SKILL.md`.

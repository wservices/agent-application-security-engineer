Deepened the **application-security-engineer** role from scaffold to a tested,
script-backed depth bar. No behavior change to the advisory, read-only posture.

Added six offline, stdlib-first scripts under `scripts/` (argparse CLI,
`main(argv)`, side-effect-free, never execute analyzed code):

- `sarif_summarize.py` — parse a SARIF v2.1.0 report (Semgrep/CodeQL/Bandit/ZAP),
  dedupe results, drop suppressed, roll up by severity/rule/file.
- `sca_audit.py` — normalize an OSV-style list, osv-scanner, or npm `audit --json`
  report into vulnerable deps by severity with the fixed/patched version.
- `dependency_diff.py` — diff two manifests (requirements.txt-style or lockfile
  JSON) for added/upgraded/downgraded/removed deps and flag unpinned entries.
- `secure_code_review.py` — language-aware static review for risky constructs
  (eval/exec, shell=True, SQL string-building, pickle/yaml.load, md5/sha1/DES,
  innerHTML/document.write/dangerouslySetInnerHTML) with file:line + CWE + severity.
- `threat_model_stride.py` — enumerate STRIDE threats per element from a YAML
  model and render a threat-model table.
- `appsec_report_build.py` — merge normalized SAST + SCA findings into one
  prioritized Markdown report ranked by severity, with counts.
